# Route table

| URL | Component | Purpose |
|---|---|---|
| `/` | `DashboardPage` | Overview |
| `/students/me` | `StudentProfilePage` | Current student profile |
| `/students/:studentId` | `StudentDetailPage` | Parameterized student detail |
| `/courses` | `CoursesPage` | Search and select courses |
| `/registration` | `RegistrationPage` | Submit course registration |
| `*` | `NotFoundPage` | Fallback route |
